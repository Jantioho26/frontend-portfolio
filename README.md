# Developer Portfolio — Personal Website

A responsive personal portfolio website showcasing my frontend development projects, technical skills, and experience. Built to provide an interactive way for employers and recruiters to explore my work and connect with me.

## Technologies Used

- React — version to confirm
- Tailwind CSS — version to confirm
- JavaScript (ES6+)
- HTML5
- CSS3
- Vercel — deployment
- Additional dependencies — to confirm

## Features

- **Project Showcase:** Displays development projects with descriptions, technologies, and links to live applications and GitHub repositories.
- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices.
- **Interactive Navigation:** Smooth navigation between portfolio sections.
- **Contact Options:** Interactive contact section with a working email contact option.
- **Resume Access:** Dedicated resume button that opens my PDF resume in a new tab.
- **Light and Dark Modes:** Theme-specific styling for a consistent user experience.
- **Modern UI:** Clean layouts, interactive buttons, and hover effects.

## How to Run Locally

1. Clone the GitHub repository and navigate to the project folder.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL displayed in your terminal.

## Deployment

Deployed using Vercel.
